# מדריך לתושבי שריגים

האתר: https://srigimdovrut.github.io/srigim-info/

## איך מעדכנים את התוכן
כל הטקסט באתר נמצא בקובץ `content.md`.
1. פותחים את [content.md במצב עריכה](https://github.com/SrigimDovrut/srigim-info/edit/main/content.md)
2. משנים את הטקסט (בראש הקובץ יש מדריך עריכה קצר)
3. לוחצים **Commit changes**
4. תוך דקה-שתיים האתר מתעדכן

קבצים נוספים:
- `index.html` – עיצוב ומבנה האתר (לא צריך לגעת)
- `docs/` – מסמכי PDF שמקושרים מהאתר
